# grapevine-chip

This repo holds probe and SNP selection notes and design files for the 167K grapevine capture panel and follow-on arrays.

## This is not

This is not calling, ancestry, identity, or PCA reports. Those products live in [grapeancestry](https://github.com/Xuzhen-Li/grapeancestry).
This is not aDNA-specific capture or damage work. That line is [grapevine-adna](https://github.com/Xuzhen-Li/grapevine-adna).
This is not a nuclear pangenome or PAV graph. That line is [vitis-pangenome](https://github.com/Xuzhen-Li/vitis-pangenome).

- Not a FASTQ-to-VCF pipeline
- Not an ancestry or identity report
- Not a substitute for the 167K analysis product

## What will land later

Methods, scripts, and notes only.

- Probe and SNP selection notes for 167K and follow-on arrays
- Design-file layouts and QC checklists
- Pointers to public array resources when they exist

No unpublished genotypes, private coordinates, or sample-level matrices.
